## 🎯 1. Objective

To explore the architecture, benefits, and operational mechanics of **Software as a Service (SaaS)** cloud applications using **Google Workspace**. The experiment demonstrates cloud document drafting, multi-user real-time concurrent editing, collaborative commenting workflows, version history and rollback auditing, tabular data calculations in cloud spreadsheets, and visual presentation design.

---

## 👥 2. Collaborative Modules Demonstrated

| Task Module | Google Workspace App | Key Features & Evidence Evaluated |
| :--- | :--- | :--- |
| **1. Cloud Storage & Setup** | **Google Drive** | Explored SaaS dashboard, centralized storage quota (7.33 GB of 15 GB), and app launchers |
| **2. Document Collaboration** | **Google Docs** | Structured documentation, real-time concurrent editing, contextual comments, and version history |
| **3. Spreadsheet Operations** | **Google Sheets** | Tabular data entry, formula calculations (`=SUM`, `=AVERAGE`, `=MAX`, `=MIN`), multi-user cell cursors |
| **4. Presentation & Media** | **Google Slides** | Co-authored 4-slide deck featuring high-resolution cloud vector graphics and architecture diagrams |
| **Online Communication** | **Meet / Teams / Zoom** | Theoretical overview of video conferencing, screen sharing, and persistent channel communication |

## 🛠️ 3. Step-by-Step Procedure

### Step 3.1 — Cloud Document Collaboration (Google Docs)
1. Initialize a blank document titled `Cloud Computing Lab 7 – Collaborative Document`.
2. Format content with structured headings, introductory text, and feature comparison tables.
3. Share the document with collaborator with **Editor** role permissions.
4. Highlight targeted sections and attach threaded comments with resolution controls.
5. Access **Version History** (`Ctrl+Alt+Shift+H`) to review timestamped revisions and contributor character attribution.

### Step 3.2 — Collaborative Spreadsheet Operations (Google Sheets)
1. Create `Cloud Computing Lab 7 – Collaborative Spreadsheet`.
2. Populate student records across columns A to D.
3. Execute statistical formulas:
   ```excel
   =SUM(D2:D6)       --> Total marks evaluated (403)
   =AVERAGE(D2:D6)   --> Mean score evaluated (80.6)
   =MAX(D2:D6)       --> Maximum score identified (91)
   =MIN(D2:D6)       --> Minimum score identified (68)
   ```
4. Style headers with yellow background fill and structured borders.
5. Collaborator concurrently updates scores, triggering automatic live formula recalculation (Total: 417, Mean: 83.4).
6. Verify live multi-user avatar icons and colored cell presence boundaries.

### Step 3.3 — Collaborative Presentation Co-Authoring (Google Slides)
1. Create `Cloud Computing – SaaS Applications` slide presentation.
2. Design Slide 1 (Title slide) with modern cloud vector artwork.
3. Design Slide 2 (SaaS Definition & Architecture).
4. Design Slide 3 (SaaS Ecosystem Mindmap Diagram).
5. Design Slide 4 (Enterprise Advantages & Industry Examples).

---

## 📊 4. Result & Analysis

- **Concurrency & Synchronization:** Verified sub-second change propagation across simultaneous multi-user sessions without merge conflicts.
- **Granular Access Control:** Demonstrated role separation (Viewer, Commenter, Editor) and full auditability via revision logs.
- **Zero Client Maintenance:** Performed all productivity and analytical tasks purely through web browser interfaces.
- **Full Report:** 12 screenshots and comparative matrices are documented in [Experiment_7.pdf](Experiment_7.pdf).
